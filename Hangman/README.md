# Hangman Game

A simple command-line Hangman game developed using Python during the Datheon Engineering Cohort 2026.

## Features
- Random word selection.
- Different difficulty levels.
- Limited guessing attempts.
- Letter and whole-word guessing.
- Prevents repeated guesses.
- Displays the correct word when the player loses.
- Option to play again.

## Technologies Used
- Python 3
- Random module

## How to Run

1. Install Python 3.
2. Run the program:

```bash
python hangman.py
```
